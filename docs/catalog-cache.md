# 商品展示缓存

首页分类与商品列表使用短时缓存，默认 10 秒。通过环境变量 `CATALOG_CACHE_SECONDS=0` 可关闭；有效范围为 0–60 秒。修改配置后，按原部署方式刷新 Laravel 配置缓存。

缓存命中时，商品服务不执行列表数据库查询。商品详情、下单金额、库存检查、支付状态和卡密领取不使用此缓存。事务内调用列表查询也绕过缓存，避免把尚未提交的数据发布给其他请求。缓存读取或写入异常时仍返回实时数据库结果。

## 一致性约定

商品名称、价格、上下架、分类和展示库存允许在缓存有效期内滞后。缓存按语言分开，并继续使用应用已有缓存前缀。批量导入和直接 SQL 更新无需模型事件即可在下一次缓存到期后生效；这不是立即失效方案。若业务要求下架后首页立即消失，关闭展示缓存。购买入口始终重新检查商品状态与库存。

默认缓存中不包含卡密内容，但保留原商品列表字段以兼容现有主题。每个缓存未命中请求仍需执行原查询；此改动没有宣称消除高并发冷启动或缓存击穿，是否增加原子锁需结合生产缓存驱动和压测结果。

## 验证

`CatalogCacheTest` 使用隔离 SQLite 与 array 缓存验证：热缓存零列表查询、TTL 到期刷新、实时详情价格/库存、事务隔离、关闭缓存、缓存故障降级。当前完整 PHP 回归为 31 tests / 132 assertions。没有生产流量延迟或吞吐量测量，零查询是服务层测试结果。
