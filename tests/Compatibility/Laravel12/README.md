# Laravel 13 isolated compatibility runtime

This installs a separate candidate dependency tree and loads the actual workspace application. The root remains Laravel 6.20.42 / Dcat 2.0.24-beta. Composer scripts and plugins are disabled, platform checks stay enabled, vendor is ignored and the 129-package manifest/lock are retained for replay (100 runtime / 29 development packages). The Laravel12 directory/runtime name is historical and stays in place to preserve tested isolation paths.

Installed versions include Laravel 13.35.0, Dcat X 2.0.4, Tinker 3.0.2, Carbon 3.14.2, Guzzle 7.15.5, Symfony Mailer 7.4.19, Stripe 22.0.0, PayPal Server SDK 2.4.0 and Yansongda 3.7.20. The candidate now runs PHP 8.5.11 / PHPUnit 13.4.1 with failOnAllIssues; root retains PHPUnit 9.6.38. Shared single-line attributes/static providers preserve PHP7.4 and old-runner discovery; see [maintained framework evidence](../../../docs/laravel13-compatibility.md) and [historical shared-suite migration](../../../docs/phpunit-compatibility.md). The candidate declares PHP ^8.4; only 8.5 is tested in this round. Laravel13 receives bug fixes through Q3 2027 and security fixes through 2028-03-17. Formal deployment environment and extended operations acceptance remain pending.

Use the isolated full INI including GD, SQLite and declared extensions; the system PHP configuration stays unchanged. Bootstrap pins APP_BASE_PATH, a public fixture key, SQLite :memory:, array cache/session/mail, sync queue and default-off payment features before autoload. Native tests enable their features and replace provider/notification I/O. COMPOSER_VENDOR_DIR points discovery to this candidate.

Environment loading uses a deliberately missing candidate fixture. Config/routes/packages/services/events and storage are under tests/.runtime/laravel12. Root tests have separate tests/.runtime/storage. ExampleTest verifies exact environment/cache/storage paths and isolated DB/session/queue settings. Maintenance tests assert the runtime path before creating/removing their fixture down file.
