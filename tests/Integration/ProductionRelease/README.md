[The process regression](process-probe.php) holds a real exited child unreaped and verifies that the shared session tracker retains the live producer while ignoring the zombie, then observes a normal reap/exit. Failed reports remain separate. A successful stage or started runtime is not resumed by that mode. For a fresh replay without redownloading, stage.php --from-installed RUN_PATH copies all vendor bytes from an owned successful same-lock release into a new source/database/cache baseline, then runs original Composer installation and optimization again.
