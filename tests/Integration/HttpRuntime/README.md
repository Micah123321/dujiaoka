Archives are extracted only under tests/.runtime/http42, with SHA256/size checked against the captured HTTPS package indexes. [Download proof](../../.runtime/http42/download-proof.json) records the exact versions, source indexes, binary hashes and the absence of system installation. [Existing module runtime](../../../docs/linux-worker-compatibility.md) supplies the same PHP8.5.11 CLI, INI and shared libraries. This is a local SAPI integration fixture, not an OCI or deployment acceptance.

The [runner](run.php) creates a new private release, SQLite database, file cache/session/views, two loopback ports and independent sessions. It copies the original public/index.php byte for byte, maps its vendor to the candidate, and maps the original bootstrap/config/app/resources. The original root Composer metadata is required for application namespace detection; installed code and package discovery come from the candidate vendor. Five framework cache paths are absolute and private. There is no shop environment in this base directory. The original routes/web.php prefix is retained, followed by three [diagnostic routes](routes.php) behind the original web middleware. The [FPM prepend](prepend.php) sets the synthetic environment before autoload and records the original request lifecycle at shutdown.

The same command with `--fail-after-start` intentionally exits1 after both native masters and listeners are ready. Its FAIL summary is the expected control; check closed handles, no live original identities and both ports closed. Never classify a command exit alone as acceptance: the first exploratory package-discovery error reached Laravel's CLI renderer and exited0 without a summary; that artifact is retained.

Seventeen unique client IDs must match seventeen JSON Nginx access records. Thirteen dynamic requests must additionally match exactly one FPM event each, with method/URI/status equal. JS and CSS bodies must match the actual built Vue manifest files and MIME. Original homepage/buy, real CSRF419 and successful file-session POST, untrusted and explicitly trusted four forwarding headers, next-request reset, exact JSON500, file maintenance503/recovery and public-root404 boundaries are included. Both masters receive SIGQUIT and must exit0. Owned SID/PGID/start_ticks tracking covers native children throughout requests, waits and cleanup; it retains the session-bound coverage of the [shared helper](../ScheduleWorkerLifecycle/process.php).

E_ALL remains enabled. phpdotenv's original Reader.php:73 uses @file_get_contents on the deliberately absent private release/.env. PHP retains that suppressed E_WARNING in error_get_last even when no PHP error is reported. Raw warnings remain in every FPM event; the assertion accepts only that exact source/line/type/private path, and separately requires no PHP engine error log. It does not clear last-error state or mute reporting.

Run reports are always new directories under tests/.runtime/http-runtime. Real merchant, SMTP, production database, container image, Engine timer, root-to-application privilege changes and DSH GUI are outside this fixture.
